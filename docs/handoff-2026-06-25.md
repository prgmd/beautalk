## 2. 진행 중 / 미완 (다음 세션에서 이어서)

### 🔲 `/chat` 라우트 정리 — **시작했으나 미완**
사용자 합의: `/chat`을 삭제하지 말고 **이름 변경 + 빈 화면 간결화**로 IA 통합.

**해야 할 일 (FE 라우트 네비게이션만 변경, 백엔드 API 경로 `/chat/`·`/chat/quota/`는 그대로 둘 것!):**
- `router/index.js`: 라우트 `path: '/chat'` → `'/consult/product'` (컴포넌트는 `ChatView.vue` 유지)
- 네비게이션 참조 일괄 변경 `'/chat'` → `'/consult/product'`:
  - `views/DashboardView.vue` (상담 추천 카드 `go('/chat')`)
  - `views/ConsultHubView.vue` (`go('/chat')`)
  - `views/SkinConsultView.vue` (`router.push('/chat')` — "이 타입으로 추천받기")
  - `views/OnboardingView.vue` (2곳: `skipOnboarding`, `goChat`)
  - `views/AuthCallbackView.vue` (`router.push(data ? '/chat' : '/onboarding')`)
  - `components/GlobalSidebar.vue` (`isActive`의 `p === '/chat'`)
- `views/ChatView.vue` 빈 화면(empty state): 홈과 겹치는 큰 인사말·날씨 환영 블록을 **상담 도입부("무엇을 찾으세요?")로 간결화**. 앱바 날씨 뱃지·남은 대화 칩·조건 좁히기·추천 흐름은 유지.
- ⚠️ **주의**: `stores/chat.js`의 `api.post('/chat/')`, `api.get('/chat/quota/')`는 **백엔드 엔드포인트**라 절대 바꾸지 말 것.

### 🔲 (논의됨, 미착수) 상담 추가 기능 — 1순위 "스킨케어 루틴 설계"
- 피부 타입+고민 → 클렌저→토너→세럼→크림→선크림 단계별 실제 제품 추천
- 기존 `form` 분류 + 가격 필터 + RAG 재활용. 진단→루틴→개별추천 흐름 완성
- 2순위: 예산 화장대 / 3순위: 제품 비교(LLM 없이도 가능)
