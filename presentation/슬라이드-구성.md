## 부 03. 설계 (6.5분)

### 11. 아키텍처 (03-설계-아키텍처.md)
- **내용:** 브라우저(Vue) ↔ Nginx ↔ Django ↔ (DB + 외부 AI) / 역할 분리로 원인 추적 용이 / **API 23개 · 테스트 63개 · 화면 13개**

### 12. 데이터 설계 (ERD) + 프론트
- **내용:** ERD = "엑셀 시트 여러 장 + 잇는 끈" / Vue SPA(새로고침 없음)·라우터 가드·자동 토큰 갱신·디자인 토큰
- **비주얼:** 🎨 ERD 큰 그림(사용자·제품·게시글 연결) + 작은 박스로 프론트 4키워드

### 13. 데이터 확보와 정제 (03-설계-데이터확보.md)
- **내용:** 4단계 **수집(크롤링)→AI 요약→정제→fixture** / 306종·커버리지 99.7% / "데이터가 알려주는 대로 길을 바꾼" 이야기
- **비주얼:** 🎨 4단계 파이프라인(올리브영 → AI요약 → 정제 → products_seed.json → loaddata)

### 14. 인증·보안 (03-설계-보안.md)
- **내용:** OAuth(비번 안 받음) / JWT 출입증(서명) / **git 키 0건** / 출입증 분리 보관(메모리 30분 + 쿠키 7일)
- **비주얼:** 📷 `git ls-files | grep env` 터미널 결과(공개 URL 한 줄만) + 🎨 로그인 흐름 화살표

### 15. ⭐ 하이브리드 추천 — 문제 (03-설계-RAG-하이브리드.md)
- **내용:** "지성·2~3만원·로션" 요청 → 토너 16,900 / 세럼 5,700 / 크림 추천 → **명백한 오추천 ❌** / 왜? AI는 "비슷한 것"만 잘 찾고 "조건 거절"은 못 함
- **비주얼:** 📷 실패 캡처 + 빨간 ❌ 강조 + 한 줄 비유 "AI는 '이건 로션이 아니다'라고 거절 못 한다"

### 16. ⭐ 하이브리드 추천 — 해결 (2겹 구조)
- **내용:** **"하드 조건은 SQL, 부드러운 취향은 AI"** / ① SQL 필터(위반 제품 통째 제외) → ② 임베딩 코사인 정렬(RAG=도서관 사서) → ③ AI가 3개 선택
- **비주얼:** 🎨 3단 파이프라인 다이어그램(①에서 크림 사라지는 모습 강조)

### 17. ⭐ 하이브리드 추천 — 증명 (✓/✗ + 측정)
- **내용:** AI가 위반 제품을 **볼 수조차 없음** → 구조적으로 불가능 / 조건 완화는 순서대로+✓/✗ 정직 표기
- **★ 차별점 — 추천 품질을 숫자로 검증:** `eval_recommend` 자동 평가 → **완화 없는 구간 제형·가격 충족률 100%** / 전체 15쿼리 92%·82%(완화 3건은 정직 표기)
- **비주얼:** 📷 결과 카드 ✓/✗ 배지 + 완화 배너 / 📷 `eval_recommend` 실행 결과 표(터미널 캡처) / 📊 충족률 표
- **멘트:** "대부분의 팀이 '추천이 좋다'고 주장만 합니다. 저희는 명령어 한 줄로 **측정**합니다 — 완화 없는 구간은 충족률 100%."

### 17-b. ⭐ 모델 선택 — 감이 아니라 실측
- **내용:** 모델 5종 직접 측정(추천/대화 지연) → **gpt-4o(3.6s) 채택** / 추론형은 effort 낮춰도 2~3배 느림 / LLM 관측은 LangSmith로 추적
- **비주얼:** 📊 모델 지연 비교 표 / 📷 LangSmith waterfall 트레이스(있으면)

### 18. 배포 (03-설계-배포.md)
- **내용:** EC2 1대(1GB) 안 Docker 3상자(db·backend·nginx) / Nginx 교통정리 / **HTTPS** / **beautalk.site 실가동**
- **비주얼:** 🎨 EC2 박스 안 Docker 3상자 + 자물쇠 아이콘 + 📷 주소창 캡처
