# 02-1. 기능 소개 — 챗봇 (대화형 추천 + 피부 타입 진단)
> 발표 파트 · beautalk · 권장 1분

## 🖥 슬라이드에 넣을 것
- 상담은 두 종류: **① 화장품 추천 상담  ② 피부 타입 진단 상담**
- 추천 흐름: 대화로 조건 모으기 → [추천 3개 받기] → 제품 카드 + 이유
- 진단 흐름: 몇 가지 질문(보기/직접입력) → 건성·지성·복합성·민감성 판정 → 프로필 저장
- [캡처: 챗봇 추천 결과 카드 3개 + ✓/✗ 배지 / 피부 진단 결과 화면]

## 🎤 이렇게 말하세요
"핵심 기능인 챗봇은 두 가지 상담을 합니다.

첫째, **화장품 추천 상담**입니다. 챗봇과 짧게 대화하며 제품군·제형·가격대·피부 고민을 모으고, '추천 3개 받기'를 누르면 내 피부에 맞는 제품을 **이유와 함께** 보여줍니다. 원하면 시작 전에 제형·가격대 조건을 미리 골라 '대화 바로 시작하기'로 건너뛸 수도 있어요.

둘째, **피부 타입 진단 상담**입니다. 내 피부 타입을 모르는 분이 많잖아요. 그래서 몇 가지 질문에 답하면 건성·지성·복합성·민감성 중 어디에 가까운지 알려주고, 그 결과를 프로필에 저장해 이후 추천에 자동 반영합니다. 보기 버튼으로 답해도 되고, **'직접 입력'으로 자유롭게 적으면 AI가 가장 가까운 답에 매칭**해 줍니다.

그리고 상담 화면은 **오늘 날씨까지 반영**합니다. 흐린 날이면 '자외선 차단을 신경 써보는 건 어떨까요?' 같은 멘트로 자연스럽게 말을 겁니다."

## 💡 왜 이 선택?
- **단일 추천 vs 추천+진단 → 둘 다.** '피부 타입을 모른다'는 가장 흔한 막막함을 진단 상담으로 풀어, 진단 → 추천으로 자연스럽게 이어집니다.
- **진단 자유 입력 → LLM 매칭.** 보기만 두면 '내 경우가 없는데?'가 생깁니다. 자유 입력을 LLM이 가장 가까운 보기로 해석해 유연함과 일관성을 동시에 잡았습니다.
- (대화·추천을 어떻게 정확하게 만드는지의 기술 설계는 → **03 설계 / RAG·하이브리드 추천** 파트에서)

## ❓ 예상 질문 & 답변
**Q. 피부 타입 진단은 AI가 하나요?**
A. 현재는 규칙 기반 문답 + 자유 입력을 LLM이 보기에 매칭하는 방식입니다. 완전한 대화형 판정으로 고도화할 수 있는 구조로 만들어 뒀습니다.

**Q. 추천은 정확히 어떻게 골라지나요?**
A. 그게 발표의 하이라이트입니다. SQL로 조건을 거르고 AI로 취향을 정렬하는 하이브리드 방식인데, 설계 파트에서 자세히 보여드리겠습니다.
