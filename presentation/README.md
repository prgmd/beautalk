## 0. 이 폴더 사용법

각 파일은 **발표자가 그대로 보고 말할 수 있는 대본**입니다. 한 토픽 = 한 파일이며 구성은 공통입니다.

```
🖥  슬라이드에 넣을 것   — 화면에 띄울 핵심 (글자 최소)
🎤  이렇게 말하세요      — 실제 발표 멘트 (쉬운 말)
💡  왜 이 선택?          — 선택지 비교 → 결정 이유
❓  예상 질문 & 답변
```

## 3. 배치 전략 (어디에 힘을 주나)
1. **데모를 기능 소개 직후에.** 이론 먼저 깔면 비전공자는 지친다 → 먼저 보여주고 설명.
2. **시간의 절반을 데모 + RAG 하이브리드 추천에.** 나머지는 빠르게.
3. **RAG 파트가 하이라이트:** *"로션 추천 → AI가 크림"* 실패 한 컷 → 왜 → 해결(SQL 거름+AI 정렬) → 증명(✓/✗ 배지).
4. **슬라이드는 글자 최소, 화면 캡처·다이어그램 위주.**

## 4. 라이브 데모 스크립트 (3분)
> 슬라이드 없이 실제 화면. FE가 운전, 추천이 뜨는 순간 BE가 한마디 얹는다.

```
① 로그인(카카오)              → "비밀번호 저장 안 하고 카카오에 확인 위임"
② 홈 대시보드(날씨·프로필 요약) → 출발점 한눈에
③ 피부 타입 진단 상담          → 질문 답하면 타입 판정·저장
④ 챗봇: "지성·2~3만원대 크림 추천해줘"
⑤ 추천 3개 + 이유 + ✓/✗ 배지   ← [BE] "SQL로 거르고 AI로 정렬한 결과예요"
⑥ 둘러보기(검색·인기순·찜) + 제품 상세(AI 요약·만족도)
⑦ 커뮤니티: 글 + 제품 태그 → 댓글/좋아요
```

### ⚠️ 라이브 안전장치
- **백업 녹화 영상** 준비 — 끊기면 즉시 전환.
- 발표 직전 **추천 1회 미리 호출**(LLM 워밍업) + 쿼리 결과 확인.
- 미리 로그인된 계정 + 시드 데이터, 데모 쿼리 고정.
